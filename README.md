# Bank Loan Approval Prediction

## Project Overview

Bank Loan Approval Prediction is a machine learning internship project that predicts whether a loan application is likely to be approved based on applicant information.

The project uses Python and a Random Forest Classifier to demonstrate a complete machine learning workflow, from data preprocessing to model evaluation and prediction.

## Objectives

* Explore and preprocess loan application data.
* Handle missing values in numerical and categorical features.
* Encode categorical variables using One-Hot Encoding.
* Build a machine learning model using Random Forest.
* Evaluate model performance using classification metrics.
* Predict loan outcomes for sample applicants.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Project Workflow

1. Load and explore the dataset.
2. Identify numerical and categorical features.
3. Split data into training and testing sets.
4. Handle missing values and encode categorical features using a Scikit-learn Pipeline.
5. Train a Random Forest Classifier.
6. Evaluate the model using accuracy, precision, recall, a confusion matrix, and ROC-AUC.
7. Generate predictions for sample loan applications.

## Machine Learning Algorithm

**Random Forest Classifier**

Random Forest is an ensemble learning algorithm that combines multiple decision trees to produce a classification prediction.

## Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* Confusion Matrix
* ROC-AUC Score

Actual evaluation results are available in the Jupyter Notebook.

## How to Run the Project

1. Clone or download this repository.

2. Install the required Python libraries:

   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn jupyter
   ```

3. Open the project notebook in Jupyter Notebook or JupyterLab.

4. Ensure the dataset is available at the path expected by the notebook.

5. Run the notebook cells from beginning to end.
